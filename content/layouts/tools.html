[ Project Overview ] What Is It?

The Operator's Toolkit is a free, browser-based reference platform for wastewater treatment professionals. No login. No app to install. No ads, no vendor relationships, no content that exists to sell you something. Open it on a phone in the field or on a workstation in the control room — it works the same either way.

The toolkit covers four areas: interactive process calculators, operational reference data, field guides, and a process decision matrix for symptom-driven troubleshooting. The calculators alone cover more than two dozen common computations across activated sludge, hydraulics, solids handling, and digester operations — the math operators do by hand every shift, collected in one place.

[ Origin ] Why I Built It

These calculators started as browser bookmarks. During shift work you need the SVI before handoff, the F/M Ratio before making a wasting call, the VSR for your biosolids compliance report. The math itself isn't complicated — but reaching for a textbook or a buried spreadsheet at 2 a.m. during an upset wastes time you don't have.

I built the first few calculators for myself. A few weeks later I was sharing the link with operators on the floor. A few months after that the scope had grown past what made sense to host as a page on a personal site — calculators, a decision matrix, reference tables, field guides. It needed its own home.

Everything on the site is built the way I'd want to find it: fast to load, readable in bright sunlight on a phone screen, and useful even when you don't remember the exact formula. It's written by an operator, for operators.

[ Technical Architecture ] How It's Built

Same stack as this site: Hugo generates the static HTML and Cloudflare Pages serves it globally from the edge — no server to maintain, no database, fast everywhere. Layouts live on top of a shared scada-theme with project-level overrides.

The interactive calculators are vanilla JavaScript Web Components. No React, no framework, no build pipeline for interactivity — just the native browser platform API. Each calculator is a self-contained custom element that reads inputs and writes results. The formula pie wheels render as interactive SVG custom elements: tap a variable segment to solve for it. The live weather widget pulls from Open-Meteo, which is free and requires no API key, and surfaces heat and cold advisories operators actually care about on shift.

It is built to be field-grade: a service worker enables offline / installable use, a print stylesheet formats reference tables for paper, and every change ships through Lighthouse CI for performance and accessibility on both mobile and desktop.

The interface design is a deliberate choice. It's modeled on Foxboro-style SCADA control panels — charcoal backgrounds, yellow accent values, monospace telemetry labels. The reasoning is simple: operators in the field should feel at home in it.
